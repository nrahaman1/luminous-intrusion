# Luminous Intrusion

Interactive atlas of nighttime-light exposure likelihood across U.S. bat habitat, 1992–2022.

**Live site:** https://nrahaman1.github.io/luminous-intrusion/

Companion to: Rahaman, S. N., Shermin, N., López-Carr, D., & Pricope, N. G. (2024). *Mapping the luminous intrusion: a nationwide multidecadal emerging bivariate cluster analysis of bat habitat's exposure likelihood to nighttime light.* Landscape Ecology 39:202. https://doi.org/10.1007/s10980-024-01997-8

## Features
- Year slider (1992–2022) with play-through: exposure likelihood (bivariate z), nighttime light, bat habitat share, emerging-pattern classes
- Click any county: 31-year light trend, exposure z trend, habitat for big brown bat, silver-haired bat and little brown myotis
- **Harmonized** mode puts VIIRS (2012+) on the DMSP scale (quantile matching fit on 2011↔2012 plus a per-county anchor, 2012–14 mean = 2009–11 mean) so the sensor switch doesn't show as a jump. Toggle to **Raw** for the published values.
- Search, sortable county table, shareable county links (e.g. `#12095`)
- Responsive layout for phone, tablet and desktop

## Run locally
    python -m http.server 8765
Then open http://localhost:8765

## Data
- Nighttime light: DMSP-OLS v4 (1992–2011), VIIRS DNB v1 (2012–2022), county means via Google Earth Engine
- Habitat: USGS GAP 2001 species habitat models
- `data.js` is generated by `build_data.py` (run from the parent research folder, which holds the source CSVs)

## Map token
`config.js` sets `MAPBOX_TOKEN` and is git-ignored. For a Mapbox basemap, use a URL-restricted public `pk.` token. Without it, the map falls back to the CARTO dark basemap.
